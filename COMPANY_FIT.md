# ChronoArchive — Company and Team Fit

**Snapshot:** 2026-11-13

## Project thesis

A digital heritage prototype that lets visitors explore example countries, historical artefacts and timelines.

Matches below are potential employer/skills fit, not known customers, users, partners, endorsements or hiring interest.

## IBM

**Relevant public technical areas:** Enterprise data governance and knowledge systems.

**Potential role families:** Software Engineer, Backend Engineer, Data Engineer, Applied AI Engineer, Geospatial Engineer or Research Engineer.

**Evidence this project should demonstrate:** Static HTML/CSS/JavaScript interface with an Express API skeleton for country, timeline, artifact, museum and historical-gap endpoints. The current sample contains a small set of example records; the gap endpoint is a placeholder and is not a validated historical inference system.
